# Мини-игры

Браузерные игры для телефона на чистом HTML/CSS/JavaScript и Canvas 2D. Без фреймворков, сборщиков и зависимостей.
Каждая игра работает как отдельное PWA: ставится на экран «Домой» и работает офлайн.

| Адрес | Игра |
|---|---|
| `/` | меню со списком игр |
| `/louis/` | **Луи на прогулке**: пёс гуляет во дворе, ищет вкусняшки и игрушки, дружит с маленькими собачками, убегает от больших |
| `/neon-runner/` | **Neon Runner**: неоновый раннер на три полосы |

## Структура

```
public/
  index.html, hub.css, manifest.json, sw.js   меню игр и его PWA
  icons/                                      иконки меню
  louis/                                      Луи на прогулке
    logic.js     БАЛАНС (CONFIG, LEVELS), карта двора (WORLD) и вся симуляция
    game.js      рендер, звук, управление, экраны
    index.html, style.css, manifest.json, sw.js, icons/
  neon-runner/                                Neon Runner
    logic.js     БАЛАНС (CONFIG) и чистые функции
    game.js, index.html, style.css, manifest.json, sw.js, icons/
server.js            статический сервер на встроенном http
scripts/gen-icons.js генератор PNG-иконок всех игр (scripts/icons/*.js)
test/                автотесты (node --test)
```

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm start          # http://localhost:3000
PORT=8080 npm start
npm test           # логика обеих игр и сервер
npm run icons      # перегенерировать иконки
```

Чтобы проверить на телефоне, открой адрес компьютера в той же Wi-Fi сети, например `http://192.168.1.10:3000`.
Service worker и установка на экран «Домой» работают на `localhost` и на HTTPS.

## Деплой на Railway

Railway подключён к репозиторию: каждый пуш в `main` собирается и выкладывается сам.

Для нового проекта:

1. **New Project -> Deploy from GitHub repo**, выбери репозиторий и ветку `main`.
2. Railway запустит `npm start`. Настройки в `railway.json`: healthcheck на `/health`, перезапуск при падении.
3. **Settings -> Networking -> Generate Domain** даст публичный HTTPS-адрес.
4. `PORT` Railway выставляет сам, сервер его читает.

## Как добавить новую игру

1. Создай папку `public/<игра>/` со своими `index.html`, `manifest.json` (`start_url` и `scope` равны `./`) и `sw.js`.
2. В `sw.js` задай свой `CACHE_PREFIX`: каждый воркер удаляет только кэши со своим префиксом, иначе игры сотрут офлайн-кэш друг друга.
3. Добавь карточку в `public/index.html` и сцену иконки в `scripts/icons/`.
4. Добавь игру в список `APPS` в `test/server.test.js`.

После изменения файлов игры увеличь версию в `CACHE_NAME` её `sw.js`, чтобы установленные копии обновились быстрее.

## Луи на прогулке

Управление: веди пальцем по экрану, Луи идёт за ним. Если тянуть дальше от точки касания, он бежит, пока есть силы.
Кнопка «Нюх» показывает следы запаха к ближайшим вещам и открывает спрятанные в траве и кустах.
Рядом с маленькой собачкой нужно постоять, они понюхаются, и настроение вырастет.
Большая собака сначала лает, потом гонится. У двери подъезда безопасно, туда она не заходит.
Если догонит, Луи пугается и сам бежит к подъезду. Когда время выйдет, приведи Луи домой за бонусом.
Если настроение упадёт до нуля, Луи загрустит и прогулка закончится.

Три прогулки: утро, день и вечер в темноте с фонарями. Следующая открывается за одну звезду на предыдущей.
Рекорды, звёзды и альбом друзей хранятся в localStorage. На компьютере: стрелки или WASD, Shift - бег, пробел - нюх.

Баланс в начале `public/louis/logic.js`:

| Где | Что крутить |
|---|---|
| `WALK_SPEED`, `SPRINT_SPEED`, `STAMINA_*` | скорость Луи и сколько он может бежать |
| `BIG_CHASE_SPEED`, `BIG_NOTICE_RADIUS`, `BIG_ALERT_TIME`, `BIG_CHASE_TIME`, `BIG_LOSE_RADIUS` | насколько опасны большие собаки |
| `MOOD_DECAY`, `MOOD_FEAR_DRAIN`, `MOOD_SCARE`, `MOOD_FRIEND` | как быстро меняется настроение |
| `SNIFF_*`, `REVEAL_RADIUS`, `BUSH_ITEM_CHANCE` | как трудно искать вещи |
| `ITEMS` | очки, настроение и частота каждой вкусняшки и игрушки |
| `FRIEND_SNIFF_TIME`, `FRIEND_SCORE`, `HOME_BONUS` | дружба и бонусы |
| `LEVELS` | длительность, собаки, число вещей, скорость собак и пороги звёзд для каждой прогулки |

Внешний вид собак, в том числе цвета самого Луи, в объекте `LOOKS` в начале `public/louis/game.js`.

## Neon Runner

Свайп влево/вправо или тап по половине экрана меняет полосу. На клавиатуре: стрелки или A/D, пробел - старт, P - пауза, M - звук.

Баланс в объекте `CONFIG` в начале `public/neon-runner/logic.js`:

| Константа | Что делает |
|---|---|
| `BASE_SPEED`, `SPEED_GROWTH`, `MAX_SPEED` | стартовая скорость, прирост в секунду, потолок |
| `ROW_GAP_START`, `ROW_GAP_MIN`, `ROW_GAP_SHRINK` | расстояние между рядами и как оно сжимается |
| `DOUBLE_START`, `DOUBLE_MAX`, `DOUBLE_GROWTH` | шанс ряда с двумя препятствиями |
| `COIN_CHANCE`, `COIN_ROW_CHANCE` | частота монет и рядов без препятствий |
| `SCORE_PER_SECOND`, `COIN_SCORE` | очки за время и за монету |
| `LANE_SWITCH_TIME`, `HITBOX_SHRINK`, `SWIPE_THRESHOLD` | отзывчивость управления и прощение касаний |
