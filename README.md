# Neon Runner

Мобильная браузерная игра: неоновый аркадный раннер на три полосы, вертикальный экран.
Чистый HTML/CSS/JavaScript + Canvas 2D, без фреймворков, сборщиков и зависимостей. PWA с офлайн-режимом.

## Управление

- Свайп влево/вправо или тап по левой/правой половине экрана - смена полосы.
- На клавиатуре: стрелки или A/D, пробел - старт, P или Esc - пауза, M - звук.
- Игра сама ставится на паузу при сворачивании вкладки.

## Структура

```
public/            статика игры
  index.html       разметка, HUD и оверлеи
  style.css        стили, safe-area, неон
  logic.js         БАЛАНС (CONFIG) и чистые функции: скорость, ряды, столкновения, очки, рекорд
  game.js          игровой цикл, рендер, ввод, звук, частицы
  manifest.json    PWA-манифест
  sw.js            service worker (офлайн)
  icons/           иконки (генерируются скриптом)
server.js          статический сервер на встроенном http
scripts/gen-icons.js  генератор PNG-иконок без зависимостей
test/              автотесты (node --test)
```

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm start
```

Откроется на http://localhost:3000. Порт задаётся переменной `PORT`:

```bash
PORT=8080 npm start
```

Чтобы проверить на телефоне, открой адрес компьютера в той же Wi-Fi сети, например `http://192.168.1.10:3000`.
Service worker и установка на главный экран работают на `localhost` и на HTTPS.

Тесты (логика столкновений, очков, рекорда, генерации рядов, сервер и MIME-типы):

```bash
npm test
```

Перегенерировать иконки после правки `scripts/gen-icons.js`:

```bash
npm run icons
```

## Деплой на Railway

1. Запушь репозиторий на GitHub.
2. В Railway: **New Project -> Deploy from GitHub repo**, выбери репозиторий.
3. Railway определит Node.js по `package.json` и запустит `npm start` (`node server.js`).
   Настройки деплоя лежат в `railway.json`: команда старта, healthcheck на `/health`, перезапуск при падении.
4. Во вкладке **Settings -> Networking** нажми **Generate Domain**, чтобы получить публичный HTTPS-адрес.
5. Переменная `PORT` выставляется Railway автоматически, сервер её читает.

Через CLI:

```bash
npm i -g @railway/cli
railway login
railway init
railway up
```

После обновления игры увеличь версию кэша `CACHE_NAME` в `public/sw.js`, иначе у установленных пользователей
обновление подхватится только после следующего визита (stale-while-revalidate).

## Баланс

Все параметры в объекте `CONFIG` в начале `public/logic.js`. Вертикальные расстояния и скорости заданы в долях
высоты экрана, время в секундах, поэтому игра ведёт себя одинаково на любом разрешении и частоте экрана.

| Константа | Что делает |
|---|---|
| `BASE_SPEED`, `SPEED_GROWTH`, `MAX_SPEED` | стартовая скорость, прирост в секунду, потолок |
| `ROW_GAP_START`, `ROW_GAP_MIN`, `ROW_GAP_SHRINK` | расстояние между рядами и как оно сжимается |
| `DOUBLE_START`, `DOUBLE_MAX`, `DOUBLE_GROWTH` | шанс ряда с двумя препятствиями (одна свободная полоса) |
| `COIN_CHANCE`, `COIN_ROW_CHANCE` | частота монет и рядов-передышек без препятствий |
| `SCORE_PER_SECOND`, `COIN_SCORE` | очки за время и за монету |
| `LANE_SWITCH_TIME` | скорость перестроения |
| `HITBOX_SHRINK` | насколько хитбокс меньше спрайта (прощение касаний) |
| `PLAYER_*`, `OBSTACLE_*`, `COIN_R` | размеры объектов |
| `SWIPE_THRESHOLD` | порог свайпа в пикселях |
| `DEATH_DELAY`, `SHAKE_TIME`, `VIBRATE_PATTERN` | эффекты столкновения |

Генератор рядов гарантирует: в каждом ряду есть свободная полоса, и из любой свободной полосы предыдущего
ряда до неё можно добраться одним перестроением.
